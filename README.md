# Exploratory Data Analysis – IVG & IMG

## Project Overview

This academic project focuses on exploratory data analysis of anonymized healthcare data related to Voluntary Termination of Pregnancy (IVG) and Medical Termination of Pregnancy (IMG).

The objective is to explore, clean, transform and visualize data to better understand its characteristics and identify statistical patterns.

## Technologies Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook
- Excel

## Main Tasks

- Data loading and exploration
- Identification and treatment of missing values
- Data cleaning and transformation
- Data type conversion
- Descriptive statistical analysis
- Detection of potential outliers
- Correlation analysis and heatmap visualization

## Skills Demonstrated

Data analysis, data preprocessing, Python programming, statistical analysis and data visualization.

## How to Run

1. Install the required Python libraries.
2. Open the Jupyter Notebook.
3. Place the required Excel datasets in the project directory.
4. Run the notebook cells in order.

**Note:** The project uses anonymized healthcare data. The datasets are not included in this repository.
